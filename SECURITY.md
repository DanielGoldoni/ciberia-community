# Relatar vulnerabilidades

Para uma vulnerabilidade no código do CIBERIA, use **Security → Report a vulnerability** neste repositório. Inclua versão/commit, pré-condições, reprodução mínima com dados sintéticos, impacto e correção sugerida, se houver.

Não publique credenciais, inventários reais, URLs privadas, dados pessoais ou relatórios internos em issues públicas. Para bugs sem informação sensível, uma issue comum é suficiente.

O projeto organiza evidências e hipóteses de vulnerabilidade; não atesta a segurança de ambientes analisados. Os advisories `DEMO-*` são exclusivamente fictícios.
